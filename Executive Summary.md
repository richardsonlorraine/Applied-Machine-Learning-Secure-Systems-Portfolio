Executive Summary

This applied technical portfolio bridges the physical layer of wireless telecommunications, Radio Frequency (RF) engineering, Digital Signal Processing (DSP), FPGA hardware design, and modern machine learning. It features four advanced project implementations designed to showcase specialized technical depth across multiple interdisciplinary domains. The portfolio covers automatic modulation classification using Software-Defined Radios (SDR), automated MLOps pipelines translating PyTorch models into synthesizable VHDL hardware packages, deep learning-based channel estimation for Orthogonal Frequency-Division Multiplexing (OFDM) systems, and unsupervised convolutional autoencoders for real-time spectrum anomaly detection and jamming mitigation. Every project is structured with production-grade modularity, clean directory layouts, explicit configuration management, and robust evaluation metrics to demonstrate professional engineering readiness.
