Portfolio Summary

The portfolio is architected into four distinct, production-grade project repositories equipped with clear dependency management (requirements.txt), version control exclusions (.gitignore), configuration files, and professional documentation:

* DeepRF-Modulation-Classifier: Addresses physical-layer cognitive radio challenges by generating multi-class baseband datasets (BPSK, QPSK, 8PSK, 16-QAM) with dynamic AWGN injection. It features a residual 1D CNN trained with AdamW optimizers and cross-entropy loss, an SNR-sliced evaluation script mapping performance across discrete bins from -5dB to +20dB, and a live SDR stream buffer simulator.
* FPGA-Accelerated-Packet-Classifier: Demonstrates hardware-software co-design by executing an automated MLOps script that trains a tiny packet MLP in PyTorch, extracts weights, applies scaling factors to achieve INT8 and INT32 precision, and programmatically generates a synthesizable VHDL package (nn_weights_pkg.vhd). This package feeds directly into a pipelined MAC accelerator (fpga_nn_classifier.vhd) validated via comprehensive testbenches (tb_fpga_nn_classifier.vhd).
* DeepComms-Channel-Estimation: Simulates an advanced OFDM communication link over a multi-path Rayleigh fading channel. It builds synthetic datasets combining received subcarrier vectors and initial Least Squares (LS) pilot interpolations to train a deep neural network capable of predicting full channel frequency responses, subsequently benchmarking performance using Normalized Mean Square Error (NMSE) metrics.
* RF-Spectrum-Anomaly-Detector: Implements an unsupervised intelligence framework for electronic warfare support. By converting raw time-domain signals into STFT spectrograms, it trains a Convolutional Autoencoder exclusively on baseline "normal" background noise and authorized static carrier channels. Anomalies, such as frequency chirps and wideband/narrowband jammers, are isolated in real time by measuring pixel-wise Mean Squared Error (MSE) reconstruction loss against a predefined threshold.
